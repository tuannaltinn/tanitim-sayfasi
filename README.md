## Proje Hakkında

Bu proje, BGY207 Web Tasarımı dersi kapsamında HTML5, CSS3 ve JavaScript kullanılarak sıfırdan geliştirilmiş tek sayfalık bir kişisel tanıtım sitesidir. Sayfada anlamsal HTML yapısı, Flexbox ve Grid tabanlı duyarlı (responsive) tasarım, açık/koyu tema geçişi ve JavaScript tabanlı iletişim formu doğrulaması yer almaktadır. Proje, hiçbir hazır şablon veya harici kütüphane kullanılmadan erişilebilirlik (WCAG 2.2 AA) ilkelerine uygun olarak hazırlanmıştır.

### Yerel Bilgisayarda Açma
1. `tanitim-sayfasi` klasörünü açın.
2. Klasör içindeki `index.html` dosyasına çift tıklayarak güncel bir web tarayıcısında (Chrome, Edge, Firefox vb.) açın.
3. Proje tamamen statik HTML, CSS ve JavaScript dosyalarından oluştuğu için herhangi bir sunucu veya veritabanı kurulumu gerekmez.

## Dosya Yapısı

- `index.html`: Sayfanın anlamsal HTML yapısı ve içeriği.
- `assets/css/style.css`: Renk paleti, tipografi, Flexbox/Grid düzeni, koyu tema ve 600px altı mobil uyumluluk kuralları.
- `assets/js/main.js`: Tema değiştirme düğmesi ve iletişim formu doğrulama kodları.
- `assets/img/profil.jpg`: Hakkımda bölümünde kullanılan profil fotoğrafı.
- `README.md`: Proje tanıtım ve dokümantasyon dosyası.

## Görsel Kaynağı ve Lisansı
